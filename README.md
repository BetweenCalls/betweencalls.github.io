# Between Calls short links

Hosted on GitHub Pages. Printed QR codes point here, so these URLs must never move.

- `/android/` : Google Play QR target. Shows a "Coming soon to Google Play" page until launch.
  To switch to the live Play listing, edit `android/index.html`, delete the two lines that start
  with `<!-- LIVE-SWITCH-START` and `LIVE-SWITCH-END -->` (keep the two lines between them), and commit.
